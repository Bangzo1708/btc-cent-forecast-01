Forecasts Bitcoin's US-dollar price 4 hours ahead from the last 72 hours of 1-minute closes: the last price pulled 10% toward its 24-hour mean, a heavily-shrunk median forecast built to beat the persistence baseline on mean absolute error in cents.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
